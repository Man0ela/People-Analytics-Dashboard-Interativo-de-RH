# 📊 Dashboard de Acompanhamento de RH — Power BI

Este repositório contém o projeto de um **Dashboard Descritivo de RH** desenvolvido no Power BI. O objetivo deste painel é apresentar visões estratégicas sobre a força de trabalho da empresa, consolidando métricas demográficas, operacionais e financeiras em uma interface interativa.

---

## 📌 Principais Indicadores e Funcionalidades

- **Métricas do Quadro de Pessoal:** Total de colaboradores, média de idade geral e distribuição por departamento.
- **Análise Demográfica:** Proporção de funcionários por gênero e média de idade segmentada.
- **Análise Financeira & Salarial:** Despesas com folha de pagamento distribuídas por departamento e estado (filiais).
- **Gestão Operacional:** Acompanhamento da quantidade de faltas (absenteísmo), contratações e demissões.
- **Filtros Interativos:** Segmentação de dados dinâmica por Departamento, Nome, Gênero, Filial e Salário.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas

- **Power BI Desktop:** Modelagem de dados, criação de medidas DAX e design dos visuais.
- **Power Query:** Limpeza, transformação e estruturação das tabelas de dados.
- **Excel / Google Drive Integration:** Conexão automatizada da base de dados hospedada na nuvem.

---

## 📁 Arquivos do Repositório

- `rh-projeto.pbix`: Arquivo completo do relatório no Power BI.
- `SALARIOS.xlsx`: Base de dados utilizada para alimentar o relatório.

---

## 🚀 Como Visualizar / Testar o Projeto

1. Certifique-se de ter o **Power BI Desktop** instalado em seu computador.
2. Faça o download ou clone este repositório.
3. Abra o arquivo `rh-projeto.pbix`.
4. Clique em **Atualizar** no menu superior para sincronizar os dados da nuvem.
